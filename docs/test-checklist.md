# Чек-лист проверки на телефоне (10 минут)

Для проверки перед показом детям. Открывать **живой сайт** (https): https://danyapole.github.io/Sound-Catcher/ — только по `https` работает микрофон. Откройте адрес в самом Safari или Chrome (не внутри мессенджера или другой программы). Чтобы увидеть всё как в первый раз, добавьте в конец адреса `?fresh`. Звук телефона включён (на iPhone проверьте переключатель беззвучного режима сбоку).

Отмечайте галочками. Если что-то не так — запишите: модель телефона, браузер и версия, что именно (скриншот без личных данных).

## 1. Что ребёнок видит первым (1 мин)

- [ ] Страница открылась, **нет белого экрана**. Если приложение не смогло запуститься, должен быть экран «Что-то пошло не так» (после слияния ветки `z5-white-screen`); пришлите его текст.
- [ ] Заставка: ребёнок с сачком, «Звуколовка», «Лови звуки!» (≈ 3 с или коснуться, чтобы пропустить; при повторном открытии без `?fresh` сразу главный экран).
- [ ] Главный экран: большая красная кнопка с микрофоном, подпись «Нажми на кнопку и разреши микрофон. Тогда можно ловить звуки!», кнопка «🐦 Попробовать без микрофона».
- [ ] Всё крупное, текст читается, ничего не уходит за край экрана, нет горизонтальной прокрутки.

## 2. Запись с микрофона (2 мин)

- [ ] Нажать красную кнопку 🎤 → телефон спросил разрешение → «Разрешить».
- [ ] Сказать «Привет!» (2–3 секунды). Шкала уровня «тихо | хорошо | громко» двигается.
- [ ] Нажать кнопку ещё раз (стоп). Появились волна, плеер вверху (▶), плитки эффектов.
- [ ] Нажать ▶: слышно свою запись, громкость нормальная (не оглушает, не едва слышно).
- [ ] Отказ в доступе (если нажали «Запретить»): понятное сообщение «Микрофон не разрешён…», а не пустой экран.

## 3. Готовые звуки (1,5 мин)

- [ ] На главном экране «🐦 Попробовать без микрофона» (или «🎁 готовые» в «Мои звуки»): открылось окно с девятью звуками (птичка, пианино, гармошка, варган, кошка, собака, корова, лягушка, курица).
- [ ] Выбрать «птичка», затем «пианино»: звук играет сам, волна рисуется, плитки доступны.
- [ ] ✕ в окне закрывает его; касание вне окна тоже.

## 4. Эффекты и названия (2 мин)

- [ ] Нажать плитку «Эхо»: яркая рамка, «25%», звук изменился. Ещё нажатия: 50 %, 100 %, потом выкл.
- [ ] **Долгое нажатие** на плитку (около полсекунды): появляется название эффекта, а эффект не включается.
- [ ] Быстрое касание по плитке по-прежнему включает эффект.
- [ ] ⚙️ в шапке → «Подписи под плитками» → включить: под плитками названия (в том числе «Задом наперёд» в две строки). Выключить: подписи исчезли. После перезагрузки страницы выбор сохранился.
- [ ] Прокрутить страницу: подсказка с названием не остаётся висеть на месте.

## 5. Кнопка «отменить» и строка «Звучит» (2 мин)

- [ ] Включить один-два эффекта, подвинуть ползунок «Сухо — мокро». Нажать **↶ назад**: последнее изменение отменилось (звук и плитки). **↷ вперёд** возвращает.
- [ ] **↺ всё** сбрасывает всё: звук как был, «Звучит: как было».
- [ ] «Звучит: N ▾» показывает число изменений в одной строке (ничего не обрезано). Нажать: открылся список плашек с ✕; ✕ выключает одну настройку. Esc или касание вне панели закрывает (на телефоне — касание вне).
- [ ] **⇄ сравни**: звук «как было» без эффектов; ещё раз — снова с эффектами.
- [ ] «✨ Чистый звук» включается и выключается; правки нот (если были) остаются на месте.

## 6. Отправка и финал (1,5 мин)

- [ ] «📤 Отправить звук»: открылось окно «поделиться» или файл сохранился, есть сообщение «Звук сохранён 💾» или «Отправлено! 🎉».
- [ ] Быстро потыкать по плиткам и кнопкам 5 секунд: искры и вспышки не мигают чаще трёх раз в секунду, ничего не слепит (ограничитель вспышек: эта проверка относится к версии после слияния ветки `flash-limit`).
- [ ] Режим 🎨 «параллельный мир» (по желанию): включается, фон тёмный и плавный, нет резких мерцаний; повторное нажатие 🎨 возвращает обычный вид.
- [ ] При первом входе в 🎨 спрашивает «Показать, как играть?»: «Да, покажи!» → выбор «Ребёнок / Взрослый», шаги засчитываются по действию; «Пропустить» закрывает обучение.
- [ ] Ничего не зависло, телефон не греется сильно за 10 минут.
