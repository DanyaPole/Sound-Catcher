# Звуколовка

Веб-приложение для детей: записал звук микрофоном, поиграл с ним (16 эффектов), посмотрел на него (волна, спектр, картинка, ноты) и отправил. Страница `index.html` без зависимостей; рядом значки (`icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`) и `manifest.json` для «Добавить на экран Домой» — на GitHub Pages загружать все эти файлы вместе.

Вверху — шапка с названием и круглыми кнопками (🎨, в мире ещё ❓ и 🔔). Она часть страницы и ничего не перекрывает. Заставка показывается только при первом запуске (и с `?fresh`), дальше приложение открывается сразу.

## Режим «Художник звука» (параллельный мир)

Кнопка 🎨 в шапке превращает приложение в «параллельную реальность». Главный закон: **что видишь, то и слышишь**. Все визуальные элементы читают настоящий звук, ничего не рисуется «для красоты».

| В мире | Что происходит |
|---|---|
| Фон | Живой тёмный мир: облака дышат от реального уровня, цвет следует температуре, яркость громкости |
| Запись 🖌️ | Голос рисует во время записи: высота тона — вертикаль, громкость — толщина мазка, цвет — полоса спектра |
| Воспроизведение | Звук после эффектов рисует картину; светлая развёртка бежит со скоростью звука |
| 16 эффектов | У каждого своя кисть из реальных параметров DSP (эхо 0,28 с, варп 2,5 Гц, НЛО 7 Гц, ретро 3/6/12, хор 16/24/32 мс…) |
| Касания | Касание пустого места — круг и нота пентатоники; свайп вбок — температура звука |
| «Мои звуки» | Запись как маленькая картина 36×12 из настоящего спектра |
| Холст эха | Рисуешь, где и каким прозвучит эхо: X — когда (0–3 с), Y — высота и яркость, цвет — ухо (голубой левое, белый центр, янтарный правое), густота — как часто |
| 🖼️ | Сохранить или отправить картину звука PNG (вместе с холстом эха) |

Режим слышен только в мире и только при включённом выключателе «Эхо рисую я». Первый мазок или выбор готовой картины включают его сами: рисуешь — значит хочешь слышать. Выключен, и звук точно такой, как был до режима (проверяется тестами бит в бит).

### Безопасность и доступность
- Не больше 3 резких вспышек в секунду: громкость сглаживается (нарастание ≥ ~120 мс), вспышки эх нарастают ≥ 60 мс и ограничены по размеру и числу (≤ 256).
- «Уменьшить движение»: чернильный переход заменяется затемнением, фон не плывёт, круги не растут, анимации плиток отключены. Рисование звуком остаётся (это данные).
- Панорама не только цветом: подписи Л/Ц/П и «левое ухо / центр / правое ухо».
- Число эх подстраивается под устройство (24 / 18 / 12 по `hardwareConcurrency`).

### Устройство
- `SA-CORE` в `index.html` — чистый JS без DOM и Web Audio: сетка холста, слепок (накопленные суммы), выборка с seed, план эх, пресеты, `saBrush`. Все константы в одном объекте `ARTIST`.
- Эха — отдельные проигрыши записи в общем графе `build()`: остальные эффекты действуют и на них; одинаковый seed и холст дают одинаковый звук при воспроизведении и сохранении.
- Мир (`W`): три слоя — фон под интерфейсом, картина и «слой света» над интерфейсом (`mix-blend-mode: screen`, касания проходят насквозь).
- Холст эха (`EC`): рисование, отмена (40), предпросмотр касанием, всплески по `playT`, сохранение в `localStorage`.
- Под холстом две строки кнопок: инструменты и краски, справа столбец действий (назад, вперёд, 🎲, очистить); готовые картины — одна лента. «Сила холста» и «Размытие» — для взрослых, свёрнуты под «⚙️ Ещё».
- Фон мира рисуется в обычной плотности (размытые облака не теряют в качестве, а точек вчетверо меньше на экранах ×2); в тишине — 10 кадров/с.

## Обучение (для малыша и для взрослого)

Новичку кнопка 🎨 подсвечена и подписана «Нажми!». При первом входе в мир спрашивает «Как будем играть?»: 🧒 Малыш, 🧑 Взрослый или «Разберусь сам». Кнопка ❓ в мире открывает выбор снова.

- **Малыш (6 шагов):** сказать в микрофон → смотреть, как звук рисует → тронуть экран → нажать на слона → нарисовать точки (эхо включается само) → награда. Фразы до 7 слов с эмодзи, бабочка 🦋 читает их вслух (если у телефона есть русский голос).
- **Взрослый (5 шагов):** записать звук → выбрать эффект → включить «Эхо рисую я» → голубым пером на холсте услышать эхо слева (кнопка «Показать как») → короткий итог про 🎲, пресеты, свайп температуры и 🖼️.
- **Принципы:** шаг засчитывается по действию, а не по «Далее»; подсветка не блокирует нажатия; если застрял — через 25 с появляется «Пропустить шаг»; «Пропустить» закрывает всё; нет микрофона — «🐦 Готовый звук»; шаг, который уже выполнен, пропускается сам; при «уменьшить движение» анимации бабочки, рамки и руки отключены.

## Тесты

Нужны Node 20+ и Google Chrome. Chrome запускается без отладочного порта (его может запрещать политика системы): страница сама присылает результат на локальный сервер.

```
node tests/artist-core.test.js   # ядро: 52 проверки (выборка, хи-квадрат, пресеты, кисти)
node tests/artist-sound.js       # звук режима в реальном Web Audio: время, высота, ухо, детерминизм
node tests/golden.js             # золотой рендер: режим выключен = бит в бит (--write перезаписать)
node tests/world.js              # мир: звук и голос рисуют, развёртка, запись с поддельного микрофона
node tests/world3.js             # кисти 15 эффектов, жест температуры, галерея
node tests/echo.js               # холст эха: рисование, звук, всплески, отмена, сохранение
node tests/polish.js             # стоимость кадра, число эх, экспорт картины, «уменьшить движение»
node tests/layout.js             # раскладка 375×812: шапка ничего не перекрывает, кнопки ≥ 44 px, значки — файлами
node tests/player.js             # плеер: прилипает к верху, повтор, кусочек, касание волны, сухо — мокро, 🎲
node tests/notes.js              # ноты: тянуть вверх-вниз (звук правда меняется), ⬆️ ⬇️ ↺ 🎲 мелодия
node tests/tour.js               # обучение: оба сценария настоящими действиями, раскладка, перезагрузка в мире
```

Тестовый вход в приложении включается только адресом `index.html#sa-test` и в обычной работе не виден. Картинки для просмотра сохраняются в `tests/out/` (не коммитятся).

Известное: эффект «Хор» в самом Chrome не воспроизводится бит в бит, поэтому в золотом тесте его случаи и случаи режима сравниваются по уровню (RMS ±0,1%).
