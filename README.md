# Звуколовка

Веб-приложение для детей: записал звук микрофоном, поиграл с ним (24 эффекта, нарезка ✂️, ноты, повторы), посмотрел на него (волна, спектр, картинка, ноты) и отправил. Страница `index.html` без зависимостей; рядом значки (`icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`) и `manifest.json` для «Добавить на экран Домой» — на GitHub Pages загружать все эти файлы вместе.

Вверху — шапка с названием и круглыми кнопками (🎨, в мире ещё ❓). Она часть страницы и ничего не перекрывает. Заставка показывается только при первом запуске (и с `?fresh`), дальше приложение открывается сразу.

## Экран: что где

- **Сверху закреплён плеер** (виден при прокрутке): ▶/⏹, волна (касание — играть с места, провести вбок — кусочек), повтор ➡️🔁↔️🔀, ⇄ «сравни» — исходная запись без всякой обработки с того же места; любое изменение возвращает «с эффектами».
- **Под ним строка «Звучит»**: ↶ ↷ (отмена и повтор любого изменения звука, до 50 шагов, Ctrl+Z / Ctrl+Shift+Z), кнопка «Звучит: N ▾» (N — число изменений, при нуле «как было»; в режиме ⇄ две строки «Сейчас: как было / С эффектами: N»). По нажатию под строкой открывается список плашек всего, что меняет звук (эффекты, сухо–мокро, громкость, температура, чистый звук, ноты, нарезка, холст эха, дорожки) — ✕ на плашке выключает одно, список закрывается Esc, касанием вне панели (оно не доходит до плиток; если касание стало прокруткой — список остаётся открытым) и повторным нажатием; ↺ сбрасывает всё. В режиме ⇄ плашки нарисованы пунктиром на серой заливке. Изменение становится шагом истории, когда полсекунды не меняется или когда начинается следующее касание.
- **Плитки эффектов**: выключенная — тусклая и серая, включённая — яркая, с рамкой, «%» и точками уровня ●●○.
- **Названия эффектов**: при наведении мыши (через 0,4 с), при фокусе с клавиатуры и при долгом нажатии пальцем (0,5 с) рядом с плиткой появляется подсказка с названием; выбор эффекта быстрым касанием не меняется, а после долгого нажатия эффект не включается. Название всегда есть и в `aria-label` плитки (вместе с силой: «Замок, 25%»). Подсказка гаснет при прокрутке страницы, если плитка уехала больше чем на 2 px, и при изменении размера окна. Если приложение упало при запуске (исключение или синтаксическая ошибка до конца основного скрипта), вместо белого экрана показывается сообщение «Что-то пошло не так» и выдержка ошибки (текст и строка); ошибки уже во время работы экран не закрывают. Кнопка ⚙️ в шапке открывает настройки: «Подписи под плитками» (по умолчанию выключено, помнится в `zv-labels`).
- **Случайности**: одна широкая «🎲 Сюрприз: всё случайно» (меняет обработку, а не запись; ↶ вернёт) и маленькие 🎲 в заголовках разделов — эффекты, сухо–мокро и температура, дорожки времени; ещё 🎲 у нарезки и у нот.
- **Без микрофона**: «🐦 Попробовать без микрофона» на главном экране и на экране разрешения микрофона, потом — плитка «🎁 готовые» в «Мои звуки». Девять звуков синтезируются в коде: птичка, пианино («Во поле берёза»), гармошка, варган, кошка, собака, корова, лягушка, курица.
- **Запись**: без автоусиления браузера (`autoGainControl:false`), настоящий уровень микрофона «тихо | хорошо | громко», подсказки «очень тихо» (тише −30 дБ дольше 1,5 с) и «очень громко». Запись выравнивается до пика 0,7 и усиливается не больше чем в 3 раза — об усилении приложение говорит.
- **«Мои звуки»** хранят последние 3 записи с микрофона без эффектов; с эффектами сохраняет 📤.

## Эффекты, нарезка и случайности

- **24 эффекта**, в том числе новые: 🌪️ Вихрь (звук летает из уха в ухо, сохраняется в стерео), ✈️ Самолёт (фленджер), 🌈 Радуга (фэйзер), 📼 Кассета (плывущая плёнка), 🐌 Улитка (медленнее без смены высоты, WSOLA), 🔔 Колокол (кольцевая модуляция), 🌌 Космос (долгое эхо на октаву выше), 🦆 Утка (авто-вау).
- **✂️ Нарезка**: звук режется на 2–12 равных кусочков. Их можно перетащить пальцем, перемешать 🎲 (некоторые кусочки переворачиваются задом наперёд) и вернуть ↺. «До эффектов» режется запись, а эффекты звучат поверх неё. «После эффектов» режется уже обработанный звук, и хвосты эха рвутся вместе с кусочками. Режется только слышимая часть (окна 10 мс не тише −26 дБ от самого громкого), поэтому тишина по краям и тихий хвост эха не становятся пустыми кусочками. Границы кусочков идут не через равное время, а через равную долю громкости: при любом числе кусочков (2–12) ни один не выпадает на паузу между словами или нотами (кусочек не короче 40 мс). На речи с паузами самый тихий кусочек при 11 был в 200 раз тише самого громкого, теперь в 2,7 раза. Длина звука не меняется, стыки плавные (6 мс). Когда кусочки по порядку, звук совпадает с исходным бит в бит.
- **«✨ Чистый звук»** громкость не поднимает (не громче исходной записи) и правки нот не стирает: правка переезжает на ту же ноту, а если ноту не нашёл — так и говорит.
- **Выход**: температура → громкость → мягкий потолок (до 0,85 звук не меняется, выше плавно прижимается, никогда не выше 1). Компрессора нет: `DynamicsCompressor` в Chrome сжимал звук и ниже порога (хвосты нот на 2–4 дБ громче). Чтобы без него громкие эффекты не стали слишком громкими, Рация, Рок, Под водой и Кассета подрезаны: все 23 эффекта на любой силе не громче −6 дБFS по звучащей части (тест X3 в clarity.js). Проверено на речеподобном сигнале, на слух нет.

## Режим «Художник звука» (параллельный мир)

Кнопка 🎨 в шапке превращает приложение в «параллельную реальность». Главный закон: **что видишь, то и слышишь**. Все визуальные элементы читают настоящий звук, ничего не рисуется «для красоты».

| В мире | Что происходит |
|---|---|
| Фон | Живой тёмный мир: облака дышат от реального уровня, цвет следует температуре, яркость громкости |
| Запись 🖌️ | Голос рисует во время записи: высота тона — вертикаль, громкость — толщина мазка, цвет — полоса спектра |
| Воспроизведение | Звук после эффектов рисует картину; светлая развёртка бежит со скоростью звука |
| 24 эффекта | У каждого своя кисть из реальных параметров DSP (эхо 0,28 с, варп 2,5 Гц, НЛО 7 Гц, ретро 3/6/12, хор 16/24/32 мс…) |
| Где рисовать | Фон мира только показывает звук: касания и свайпы по нему ничего не делают (подпись «👀 Фон — это картина твоего звука»). Рисуют только в двух местах — в пунктирных рамках «✏️ Рисуй здесь»: холст эха и дорожки времени |
| «Мои звуки» | Запись как маленькая картина 36×12 из настоящего спектра |
| Холст эха | Рисуешь, где и каким прозвучит эхо: X — когда (0–3 с), Y — высота и яркость, цвет — ухо (голубой левое, белый центр, янтарный правое), густота — как часто |
| 🖼️ | Сохранить или отправить картину звука PNG (вместе с холстом эха) |
| 〰️ Дорожки времени | Линия слева направо меняет звук по ходу проигрыша: 🔊 громкость (тишина…×1,4), 🎵 высота (±12 полутонов; выше — звук быстрее кончается), 👂 ухо (левое…правое, стерео), ✨ яркость (±15 дБ выше 2,5 кГц), 🔮 волшебство (доля эффекта: вверху весь, внизу звук как был). Формы 📈📉🌊⛰️📶💓 (у высоты ступеньки — аккорд), 🎲 линия (у высоты — мелодия пентатоники), ↺, 🎲 «всё» в заголовке раздела. Касание дорожки сразу играет кусочек записи с этим значением |

Режим слышен только в мире и только при включённом выключателе «Эхо рисую я». Первый мазок или выбор готовой картины включают его сами: рисуешь — значит хочешь слышать. Выключен, и звук точно такой, как был до режима (проверяется тестами бит в бит).

### Безопасность и доступность
- **Вспышки: не больше 3 в секунду.** Новая вспышка (круг от удара, всплеск эха) появляется не чаще 3 раз за любой отрезок в 1 с (скользящее окно, `flashGate` в `index.html`); лишние не рисуются. Звук и план эх не меняются, а сами эха по-прежнему видны на холсте нарисованными. Без ограничителя худший случай («Пинг-понг» в режиме «по кругу») давал до 21 вспышки в секунду. Размах яркости слоёв света не больше ~2% яркости экрана (порог WCAG для общей вспышки — 10%; цифра по памяти, первоисточник не перечитывался). Громкость сглаживается (нарастание ≥ ~120 мс), всплески эх нарастают ≥ 60 мс. **Не измерено:** яркость всего экрана целиком (только слои света и холст эха), движение анимаций плиток (это не свет; отключается «уменьшить движение»), реальный телефон.
- «Уменьшить движение»: чернильный переход заменяется затемнением, фон не плывёт, круги не растут, анимации плиток отключены. Рисование звуком остаётся (это данные).
- Панорама не только цветом: подписи Л/Ц/П и «левое ухо / центр / правое ухо».
- Число эх подстраивается под устройство (24 / 18 / 12 по `hardwareConcurrency`).

### Устройство
- `SA-CORE` в `index.html` — чистый JS без DOM и Web Audio: сетка холста, слепок (накопленные суммы), выборка с seed, план эх, пресеты, `saBrush`. Все константы в одном объекте `ARTIST`.
- Эха — отдельные проигрыши записи в общем графе `build()`: остальные эффекты действуют и на них; одинаковый seed и холст дают одинаковый звук при воспроизведении и сохранении.
- Мир (`W`): три слоя — фон под интерфейсом, картина и «слой света» над интерфейсом (`mix-blend-mode: screen`, касания проходят насквозь).
- Холст эха (`EC`): рисование, предпросмотр касанием, всплески по `playT`, сохранение в `localStorage`; отменяют мазки общие ↶ ↷.
- Под холстом две строки кнопок: инструменты и краски, справа 🎲 и «очистить»; готовые картины — одна лента. «Сила холста» и «Размытие» — для взрослых, свёрнуты под «⚙️ Ещё».
- Фон мира рисуется в обычной плотности (размытые облака не теряют в качестве, а точек вчетверо меньше на экранах ×2); в тишине — 10 кадров/с.

## Обучение (для малыша и для взрослого)

Новичку кнопка 🎨 подсвечена и подписана «Нажми!». При первом входе в мир спрашивает «Как будем играть?»: 🧒 Малыш, 🧑 Взрослый или «Разберусь сам». Кнопка ❓ в мире открывает выбор снова.

- **Малыш (6 шагов):** сказать в микрофон → смотреть, как звук рисует → нажать на слона → нарисовать точки (эхо включается само) → провести линию высоты (звук «поёт») → награда. Фразы до 7 слов с эмодзи, бабочка 🦋 читает их вслух (если у телефона есть русский голос).
- **Взрослый (6 шагов):** записать звук → выбрать эффект → включить «Эхо рисую я» → голубым пером на холсте услышать эхо слева (кнопка «Показать как») → дорожки времени (кнопка «Показать как» рисует ступеньки высоты) → короткий итог про 🎲, пресеты, ↶ ↷, ⇄ и 🖼️.
- **Принципы:** шаг засчитывается по действию, а не по «Далее»; подсветка не блокирует нажатия; если застрял — через 25 с появляется «Пропустить шаг»; «Пропустить» закрывает всё; нет микрофона — «🐦 Готовый звук»; шаг, который уже выполнен, пропускается сам; при «уменьшить движение» анимации бабочки, рамки и руки отключены.

## Тесты

Нужны Node 20+ и Google Chrome. Chrome запускается без отладочного порта (его может запрещать политика системы): страница сама присылает результат на локальный сервер.

```
node tests/artist-core.test.js   # ядро: 52 проверки (выборка, хи-квадрат, пресеты, кисти)
node tests/artist-sound.js       # звук режима в реальном Web Audio: время, высота, ухо, детерминизм
node tests/golden.js             # золотой рендер: режим выключен = бит в бит (--write перезаписать)
node tests/world.js              # мир: звук и голос рисуют, развёртка, запись с поддельного микрофона
node tests/world3.js             # кисти 15 эффектов, фон не реагирует на касания, рамка «Рисуй здесь», галерея
node tests/echo.js               # холст эха: рисование, звук, всплески, отмена, сохранение
node tests/polish.js             # стоимость кадра, число эх, экспорт картины, «уменьшить движение»
node tests/layout.js             # раскладка 375×812: шапка ничего не перекрывает, кнопки ≥ 44 px, значки — файлами
node tests/player.js             # плеер: прилипает к верху, повтор, кусочек, касание волны, сухо — мокро, 🎲
node tests/notes.js              # ноты: тянуть вверх-вниз (звук правда меняется), ⬆️ ⬇️ ↺ 🎲 мелодия
node tests/slices.js             # нарезка до и после эффектов, перетаскивание, 8 новых эффектов, все 🎲
node tests/flash.js              # G1: не больше 3 вспышек в секунду (по событиям и по пикселям), без ограничителя — до 21
node tests/curves.js             # дорожки времени в мире: громкость, высота, ухо, яркость, волшебство, формы, 🎲
node tests/tour.js               # обучение: оба сценария настоящими действиями, раскладка, перезагрузка в мире
node tests/clarity.js            # понятность: «Звучит», ↶ ↷, ⇄, демо и 9 готовых звуков, запись, чистый звук, выход без сжатия, ошибки JS
node tests/names.js             # названия эффектов: подсказка мышью и долгим нажатием, тап не ломается, ⚙️, подписи, aria, сохранение
node tests/serve-log.js         # serve.js: строка в лог на каждый запрос без адресов клиентов; .git и tests по сети не отдаются
node tests/errscreen.js         # упало при запуске — экран «Что-то пошло не так» с выдержкой ошибки вместо белого; при работе его нет
node tests/now.js               # строка «Звучит: N ▾» на 320/375/412 px: одна строка, ничего не обрезано, список, Esc/вне/повтор, фокус, ⇄
node tests/contrast.js          # контраст числом: подписи под плитками (худшая точка) и строка «Звучит»; светлая тема и мир, цель ≥ 4,5:1
node tests/screens.js            # снимки экрана 375×812 для разбора дизайна → tests/out/screens/
```

`tests/ui_check.py` — та же проверка интерфейса через Playwright (навык `.claude/skills/webapp-testing`) для облачной сессии: на этом компьютере Playwright не работает, потому что политика Windows запрещает отладочный канал браузера.

Тестовый вход в приложении включается только адресом `index.html#sa-test` и в обычной работе не виден. Картинки для просмотра сохраняются в `tests/out/` (не коммитятся).

Известное: эффект «Хор» в самом Chrome не воспроизводится бит в бит, поэтому в золотом тесте его случаи и случаи режима сравниваются по уровню (RMS ±0,1%).
